# Lorewright installers

| File | For |
|---|---|
| `Lorewright_0.1.0_64-bit_setup.exe` | Most Windows PCs. Pick this one if you're not sure. |
| `Lorewright_0.1.0_32-bit_setup.exe` | Older 32-bit Windows. |
| `Lorewright_0.1.0_64-bit.msi` | 64-bit, as an MSI (for installing on many computers at once). |
| `Lorewright_0.1.0_32-bit.msi` | 32-bit, as an MSI. |

To download one, click its name on GitHub, then **Download raw file** (the download button at the top right).

Windows may warn that the app is from an unknown publisher, because the installer isn't code-signed. Click **More info → Run anyway** to install.

To build them yourself: `npm run installers`.
